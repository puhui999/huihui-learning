## 仓库约定

- **一个学习方向一个顶级目录**（track），启动时才创建目录，内部自治：

  ```
  <track>/
  ├── PLAN.md          # 该方向的总计划 + 进度看板
  ├── plan/            # 阶段拆解（含知识点清单、验收标准、助教检查点）
  ├── notes/           # 笔记与踩坑记录
  └── demo-*/          # 实战项目（Java 工程直接放这里）
  ```

- **demo 随学随提交**；值得进作品集的项目，打磨完成后抽独立仓库，这里保留开发版
- **提交信息**：Conventional Commits 风格（feat / docs / fix / refactor + 中文描述），不带任何 AI 署名尾注
- **密钥纪律**：API Key 一律走环境变量，`.gitignore` 已排除 `.env` / `*-local.yml` 等

## 学习纪律

1. 每个知识点当天落成**能运行的代码**，不留"看懂了"的幻觉
2. 能用数字说话就不用感觉说话（评估、基准、监控）
3. 阶段验收通过才推进；卡住超过 2 天就求助、拆小
